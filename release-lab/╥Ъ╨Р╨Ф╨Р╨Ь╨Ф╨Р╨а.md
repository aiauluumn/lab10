# Орындау қадамдары (v1.0.0)

Бастамас бұрын `index.html` ішінде «Сіздің есіміңіз» дегенді өз атыңызға ауыстырыңыз.

## 0. Жобаны GitHub-қа салу (егер әлі салынбаса)
```bash
git init
git add .
git commit -m "Алғашқы нұсқа: басты бет, қатысушылар, CI/CD"
git branch -M main
git remote add origin https://github.com/ЛОГИН/РЕПО.git
git push -u origin main
```

## 1. Нұсқа нөмірі
Нұсқа: `v1.0.0`. CHANGELOG.md дайын.

## 2. Тег құру
```bash
git tag v1.0.0
git tag
```
Тізімде `v1.0.0` көрінуі керек.

## 3. Тегті GitHub-қа жіберу
```bash
git push origin v1.0.0
```
(немесе барлығын: `git push origin --tags`)

## 4. GitHub-та Release құру
1. Репозиторий бетінде **Releases → Draft a new release**.
2. Тег ретінде `v1.0.0` таңдаңыз.
3. Атауы: `Release v1.0.0 – Алғашқы тұрақты нұсқа`
4. Сипаттамаға CHANGELOG.md мазмұнын қойыңыз.
5. **Publish release** басыңыз.

> Бұл жобада workflow релизді өзі жасайды (5-қадам). Қолмен жасасаңыз, workflow-мен қайталанып қалмауы үшін Actions бөлімін қараңыз. Қаласаңыз, қолмен жариялаудың орнына тек workflow-ға сеніңіз.

## 5. CI/CD (қосымша)
Тег жіберілісімен **Actions** бөлімінде «Релиз жариялау» workflow-ы іске қосылады. Жасыл белгіні күтіңіз.

## 6. Тексеру
- Releases бөлімінде жаңа релизді ашыңыз.
- Тег пен commit сәйкестігін тексеріңіз.
- Сипаттаманың толық екенін қараңыз.

## Қорытынды үшін скриншоттар
1. `git tag` нәтижесі
2. Releases беті
3. Actions бетіндегі жасыл workflow
