# Release және Versioning жобасы

Зертханалық жұмыс: GitHub-та тегтер мен релиздерді басқару.

**Командасы:** Молдыр және серіктес

## Жоба құрылымы
- `index.html`, `style.css` – сайт (басты бет, қатысушылар, нұсқалар тарихы)
- `CHANGELOG.md` – өзгерістер тарихы
- `.github/workflows/release.yml` – тег жіберілгенде релизді автоматты жасайтын pipeline
- `ҚАДАМДАР.md` – зертханалық жұмыстың орындалу тәртібі

## Нұсқалау
| Бөлік | Мағынасы |
|---|---|
| MAJOR | Үйлесімсіз өзгерістер |
| MINOR | Жаңа мүмкіндіктер |
| PATCH | Қателерді түзету |
